## 1. 針對目標網站 (World of Keyboards) 的深度解析

我們深入檢測了 `https://worldofkeyboards.com/multiplication` 的源碼（包含 HTML、`math.js` 與題庫字典 `mlc.js`），其設計邏輯與痛點歸納如下：

### 🛠️ 原網站優點與基本機制
1. **模式劃分**：提供「練習模式（不限時，隨時 STOP，即時回傳作答日誌）」與「測驗模式（6 秒倒數、限時 60~300 秒、結算成績彈窗）」。
2. **題庫選題**：拆分為「全部」或各個單一數字（`2 的乘法` 到 `9 的乘法`），支援「依序出題」與「隨機出題」。
3. **計分公式**：答對 +100 分，答錯 -7 分（最低不扣至負數）。
4. **語音發音**：透過呼叫 Google TTS 預錄的靜態語音檔（例如 `/static/pronunc/5X5.mp3`）唸出題目。

### ⚠️ 原網站痛點與不足之處
1. **無行動端專屬輸入鍵盤**：在手機或平板上開啟時，必須強制彈起系統軟鍵盤，容易遮蔽算式畫面，且可能需要按「換行/確認」，嚴重影響練習節奏。
2. **缺乏實質的「階級晉升（天梯關卡）」**：原站僅能自由挑選「單一數字」或「全部」，沒有階段性晉升挑戰、過關星級評判或學習成就感。
3. **依賴後端伺服器與外部靜態語音**：若離線或斷網即無法發聲；無法進行純靜態零成本一鍵部署。
4. **視覺美學與動效較為傳統**：使用舊版 Bootstrap 樣式，缺少現代連擊（Combo）回饋、流暢計時條與徽章成就證書。
5. **缺少錯題管理機制**：無法針對學生經常失誤的難題（如 $7\times8$、$8\times9$）進行聚焦攻堅重練。

## 2. 開源專案與教學邏輯借鑑

綜合評估 GitHub 上的開源乘法練習軟體與國小數學學習曲線（如 Kumon、Times Tables Rock Stars 及台灣國小九九乘法教學指引）：
- **階梯式訓練法**：從最規律的 `2, 5` 倍數開始（建立規律認知與自信），再進入 `3, 4`，接著突破偶數 `6, 8` 與大魔王 `7, 9`。
- **逆向填空題（除法思維預備）**：如 $? \times 8 = 56$ 或 $7 \times ? = 42$，能有效活化大腦的逆向推導能力，而不僅僅是死背口訣。
- **高頻易錯陷阱特訓**：國小學童錯誤率超過 60% 的題目集中於：$7\times8, 8\times7, 6\times7, 8\times9, 6\times8, 7\times9$。

## 4. 核心功能與技術優勢

### 1. 隨機檢定考試與「能力合格證書」
- **限時檢定**：可選 60 秒（極速挑戰）、120 秒（標準）、180 秒（充裕）。
- **定量題數**：可選 20 題（快篩檢定）、40 題（標準測驗）、81 題（全表完整大考驗）。
- **結算證書**：自動計算命中率、作答速度、PR評級，並頒發附帶專屬防偽編號與戳印的「九九乘法能力合格證書」。

### 2. 零依賴雙引擎音效與語音
- **Web Audio API 合成器**：使用瀏覽器原生音頻振盪器合成清脆答對音（支援 Combo 升調）、低沉答錯音、倒數計時嗶聲與通關吹號 Fanfare，不消耗任何伺服器頻寬，無須加載外部音訊檔。
- **Web Speech API 中文真人語音**：可一鍵開啟題目朗讀口訣（如「五乘五」、「幾乘八等於五十六」）。

### 3. 自動記錄與錯題攻堅特訓本
- 作答過程中有失誤的題目會自動記錄至本地 LocalStorage 錯題庫。
- 支援「🔥 立即錯題特訓」模式，針對個人的薄弱環節進行精準專項突破。
- 建立正向激勵機制：錯題若在後續練習中**連續答對 2 次**，即會自錯題本中自動畢業除名！

### 4. 互動式 9x9 口訣對照表
- 內建一鍵查閱的九九乘法矩陣，點擊任意單元格即高亮對應行列並即時發音，方便隨時複習。

## 5. 跨裝置隨時隨地使用體驗 (行動端特化)

- **智慧虛擬大按鈕九宮格鍵盤**：
  - 專為手機、iPad/平板螢幕最佳化，避免原生輸入法彈出遮蔽題目。
  - 支援觸控震動反饋（Haptic Feedback）。
  - 具備「智慧即時自動送出」邏輯：達到答案位數且正確時自動進入下一題，提供如打字遊戲般絲滑流暢的手感。
- **實體電腦鍵盤同步支援**：
  - 支援主鍵盤數字鍵與右側九宮格數字鍵（NumPad 0~9）。
  - 支援 `Backspace`（退格刪除）、`Enter` / `Space`（送出答案）、`Esc`（退出）。
- **PWA 支援（漸進式 Web 應用程式）**：
  - 內建 `manifest.json` 與 `sw.js` (Service Worker)。
  - 在 iOS Safari 點擊「分享 ➔ 加入主畫面」，或 Android Chrome 點擊「安裝應用程式」，即可變成獨立全螢幕 App，即使完全無網路也能正常遊玩。

## 6. 免費快速佈署上網指南 (1分鐘上線)

本專案採純前端架構（Pure HTML5 + Modern CSS + ES6 Vanilla JS），無任何後端依賴，可秒級佈署於全球各大免費靜態託管平台：

### 方法 A：使用 GitHub Pages (推薦，永久免費)
1. 在 GitHub 上建立一個新的公開儲存庫（Repository），例如 `9x9-math-master`。
2. 將本專案的所有檔案（`index.html`, `css/`, `js/`, `icons/`, `manifest.json`, `sw.js`）上傳至該儲存庫。
3. 進入 GitHub Repository 的 **Settings** ➔ **Pages**。
4. 在 **Branch** 選取 `main` 分支與根目錄 `/ (root)`，點擊 **Save**。
5. 約 30 秒後，GitHub 會提供一個專屬網址（例如：`https://<你的帳號>.github.io/9x9-math-master/`），全世界任何裝置皆可立即使用！

### 方法 B：使用 Cloudflare Pages / Vercel / Netlify
1. **Netlify (最速拖曳上線)**：
   - 前往 [Netlify Drop](https://app.netlify.com/drop)。
   - 直接將本專案整個資料夾拖曳進去，10 秒內即自動產生公開 HTTPS 網址！
2. **Cloudflare Pages / Vercel**：
   - 連結 GitHub 儲存庫，Build command 留空，Output directory 設為根目錄即完成佈署。

### 方法 C：本機直接使用
- 免連網：直接在任何電腦雙擊 `index.html` 即可在 Chrome / Edge / Safari / Firefox 離線運作。
