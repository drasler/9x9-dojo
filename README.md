## 3. 感官雙模分離：視覺讀寫 vs 聽力聽寫盲測

為了徹底訓練「手、眼、耳、腦」的全面協同，本專案將題目呈現方式分離為兩大維度：

1. **📖 視覺讀寫模式 (Visual Reading)**：
   * 題目於畫面正中央巨幅呈現（如 `7 × 8` 或 `? × 9 = 63`）。
   * 適合視覺敏銳型訓練與建立數字字形認知。
2. **🎧 聽力聽寫盲測模式 (Audio Dictation)**：
   * 螢幕**隱藏算式**，改為顯示科技感音波動畫與「🎧 請聽口訣心算作答」。
   * 自動調用繁體中文發音唸出題目口訣（如「七乘八」或「幾乘七等於四十二」）。
   * 鍛鍊純聽覺神經至手指鍵盤的肌肉記憶，避免依賴視覺停留。
   * 介面附有「🔊 重聽口訣一遍」按鈕（亦可按實體鍵盤 `R` 鍵隨時重聽）。
3. **自訂特訓支援**：
   * 在「自由專項特訓」面板中，使用者可自由指定感官模式（讀寫 / 聽寫 / 雙模混合）。

## 4. 錯題 3 天限時消除與降階懲罰機制

為杜絕「錯題放著不練」的惰性，系統建立了艾賓浩斯記憶遺忘曲線保護機制：

* **72 小時限時倒數**：
  * 每道答錯的算式在加入錯題本時，會自動鎖定 **3 天 (72 小時)** 的復習時效。
  * 錯題彈窗與清單即時顯示剩餘時間（如「剩餘 2 天 14 小時」；少於 24 小時則標記紅色警急）。
* **逾期降階懲罰 (Demotion Penalty)**：
  * 只要有任何錯題超過 3 天未清空，應用程式啟動時會立即執行**降階懲罰（最高解鎖階級減 1，退回前一階）**，並在畫面上方彈出醒目的紅色警示橫幅！
* **連續答對 2 次永久畢業**：
  * 點擊「🔥 立即錯題特訓」後，在特訓中**連續答對該題 2 次**，即會自錯題庫永久除名。

## 5. 跨裝置專屬設計 (行動端虛擬大鍵盤與實體鍵盤同步)

* **手機/平板專屬虛擬九宮格小鍵盤**：
  * 專為行動觸控螢幕設計，杜絕系統原生輸入法彈出擋住題目的問題。
  * 支援觸控震動反饋（Haptic Feedback）。
  * 支援「智能即時自動送出」：輸入兩位數正確答案時自動瞬跳下一題，提供如打字遊戲般極致流暢節奏。
* **電腦端實體鍵盤全支援**：
  * 支援主鍵盤數字與右側數字九宮格（NumPad 0~9）。
  * 支援 `Backspace`（退格刪除）、`Enter` / `Space`（送出答案）、`R`（重聽聽寫口訣）、`Esc`（退出）。
* **PWA 漸進式 Web 應用程式**：
  * 包含完整 `manifest.json` 與 `sw.js` (Service Worker)。
  * 可在手機/平板上點擊「**加入主畫面**」，以全螢幕獨立 App 方式離線遊玩。

## 6. 免費快速佈署上網指南 (GitHub Pages / Netlify / Vercel)

本專案採純前端無伺服器架構（Zero Backend），可 1 分鐘免費推送到網路上：

### 方案 A：使用 GitHub Pages (推薦公開 Repo 使用)
1. 在 GitHub 建立一個公開 Repository（例如 `9x9-multiplication-master`）。
2. 在本地專案終端機執行推播（工作區已建立初始 Commit）：
   ```bash
   git remote add origin https://github.com/<你的 GitHub 帳號>/9x9-multiplication-master.git
   git push -u origin main
   ```
3. 進入 GitHub Repository 的 **Settings** ➔ **Pages**。
4. 在 **Branch** 選取 `main` 與根目錄 `/ (root)`，點擊 **Save**。
5. 約 30 秒後即可取得公開網址（例如：`https://<你的帳號>.github.io/9x9-multiplication-master/`）。

### 方案 B：使用 Netlify Drop (免安裝 Git，最速拖曳發布)
1. 打開瀏覽器訪問 [app.netlify.com/drop](https://app.netlify.com/drop)。
2. 將電腦中的 `c:\MySys\9x9` 整體資料夾直接拖入瀏覽器中。
3. 10 秒內即自動產生專屬 HTTPS 公開網址。

### 方案 C：本機離線直接開啟
* 免連網：直接在任何電腦雙擊 `index.html` 即可在瀏覽器中完全離線運行。
